# 讀書計畫 — 測試檢查清單

給測試人員使用的完整功能測試清單。每一項請照「步驟」操作，並確認「預期結果」是否正確。
若結果不符，請依文件最後的「問題回報格式」回報。

- 測試版本：**1.0.0 (build 2)**
- 平台：iPhone / iPad（TestFlight）、Android、網頁版
- 網頁版：https://study-planner-260721-1286.web.app

---

## 測試前準備

- [ ] 準備 **兩個** 電子郵件帳號（測試同步與分享需要）
- [ ] 準備 **兩台裝置**（或一台手機 + 網頁版）測試跨裝置同步
- [ ] 記下你使用的裝置與系統版本（回報問題時要用）

> 小提醒：密碼至少 6 個字元。測試帳號請勿使用重要的個人密碼。
